# 🔀 Team Switch - Our Definition of Done

> Team wiki · Team Switch · Agreed in the Sprint 9 Retrospective · Applies on top of the ART-wide minimum in the PI Planning Playbook

A story is done when:

1. The code is reviewed by a second developer.
2. Unit tests are green.
3. Performance is checked: the response time is measured in the test environment and noted in the story.
