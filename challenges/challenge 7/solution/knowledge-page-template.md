# Knowledge Page Template

When I call this template, write a knowledge page in exactly this structure. Text between <<< and >>> is an instruction for you: replace it. Use only the sources I give you. If a section has no source, write "open".

### METADATA
- **Title:** <<<short and specific, for example "Decision: no story points for bugs">>>
- **Type:** <<<decision · meeting notes · how-to · team page · status · retro · playbook>>>
- **Team:** <<<Signal · Switch · Concourse · Depot · ART>>>
- **Tags:** <<<2 to 5 tags from the tag list>>>
- **Owner:** <<<a role, never the name of a team member>>>
- **Status:** <<<draft · proposed · valid · outdated>>>
- **Version:** <<<1.0, 1.1, …>>> · **Last reviewed:** <<<the story day, or a date>>>

### SUMMARY
<<<at most three sentences, with what a reader must know>>>

### DECISIONS
<<<a table, one row per decision: what was decided, who decided, when, valid until>>>

### OPEN QUESTIONS
<<<a table, one row per question: the question, who answers it, by when>>>

### DETAILS
<<<everything else, short. For type "decision": context, reasons, conditions, consequences and the voices that were heard>>>

### CHANGE LOG
<<<a table, one row per version: version and what changed>>>

### SOURCES
<<<files or pages, the sources of this page>>>

### AI LABEL AND LOG
<<<the AI label and a log line with prompt, sources, version and reviewer>>>
