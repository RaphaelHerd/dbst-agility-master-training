# 📡 Team Signal - Definition of Done

> Draft for the PI Planning page · merged by AI from our team DoD and the ART-wide minimum, wording polished

> 🏷️ AI-assisted draft · reviewed by: nobody yet

A story is done when:

1. The code is reviewed by a second developer.
2. All unit and integration tests pass in the pipeline.
3. Unit test coverage is at least 80 %.
4. The change is deployed to the shared test environment through the pipeline.
5. Every story is load-tested with peak-hour data before release.
6. Documentation is updated where needed.
