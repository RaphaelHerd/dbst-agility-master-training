When I call this prompt, write a status update in exactly this structure:

1. **Summary:** one sentence. Was the goal reached, and what is the biggest blocker?
2. **Done:** what was finished.
3. **Open:** what is not finished, and why.
4. **Next:** the next steps, and what we need from whom.

Rules:
- If I name a reader, adapt length and tone to them. If I don't, ask me who will read it.
- Use only the files I give you. Mark anything that is unclear as an open question.
- Use numbers exactly as they appear in the source. Never calculate new ones.
- Never name team members. Use pseudonyms (Member A, B …) only where a person is really needed.
- At most 120 words, unless I ask for more.
- End with the line "AI-assisted draft · reviewed by: Agility Master".
